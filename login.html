Apa itu Pengembangan Perangkat Lunak & Gim ?

PPLG adalah singkatan dari Pengembangan Perangkat Lunak dan Gim yang merupakan program keahlian di Sekolah Menengah Kejuruan (SMK). PPLG mempelajari cara pengembangan perangkat lunak termasuk pembuatan aplikasi web, mobile, software komputer, dan game dengan menguasai Coding, Desain, dan Algoritma.

Siap Kerja & Berdaya Saing Global

Siswa dibekali kurikulum berbasis industri terkini, praktek langsung dengan project riil, serta kolaborasi aktif dengan perusahaan teknologi terkemuka.

Pemrograman Web

Belajar struktur website, antarmuka interaktif, database, backend API, dan framework modern untuk menciptakan web responsif.
